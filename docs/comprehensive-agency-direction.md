# Comprehensive agency redesign — 8 November 2026

This revision changes composition across the public experience, beyond the earlier font and spacing pass.

## Research

Awwwards documents Unseen Studio as Site of the Day on 6 February 2023 (7.99), with explicit examples for project galleries, menu effects, loading, index/contact transitions and mobile layouts: https://www.awwwards.com/sites/unseen-studio . Its archived mobile capture was inspected for the large display hierarchy and strong foreground/background relationship. The live Unseen site stalled during loading in the research browser, so the documented capture informed this pass; the full current experience was not verified.

Studio Freight appears in Awwwards’ Hot Right Now 2023 publication: https://assets.awwwards.com/awards/gallery/2023/07/HOT-RIGHT-NOW-BOOK-2023.pdf . Its index, project details and contact structure provide a reference for a portfolio as an editorial system. Its current homepage is a separate design.

The previously inspected BASIC/DEPT, Studio 28K and Instrument references remain relevant to normal-width grotesque type, scale contrast and purposeful empty space. This is an original adaptation to the portfolio’s established brief, not a reproduction or a claim of matching an award score.

## Applied system

- Shared perimeter, rules, typography hierarchy, numbering, arrow geometry and image radii.
- Landing: display title, concise introduction, larger rotating service line and two linked project previews.
- Work: large title above an immersive image, overlaid project action, category/caption and previous/next controls.
- About: designed title/portrait composition with separate editorial text block.
- Services: numbered capability screens, large typography, graphic mark and indexed deliverables.
- Contact: oversized editable title, direct email action and contextual footer.
- Menu: large index and dividers, with a complementary introductory column on desktop.
- Cases: larger cover/title, readable narrative and structured chapter layout.
- Legacy typographic SVG covers updated to sans-serif graphic posters. These remain illustrative project covers, not product screenshots.

The beige/red brand colours, rounded media, four fixed corner links, precise scroll stops, letter reveals, splash sequence, reduced motion, editor data model and all content remain intact. Project previews and pagination use the same navigation system. No database changes are needed.

## Validation

TypeScript, nine existing functional tests and the production build passed. Browser checks covered 320×568 and 390×844 layouts and desktop; project next navigation, case opening, menu navigation, about, services and contact were exercised. Physical device/Safari testing was not performed.
